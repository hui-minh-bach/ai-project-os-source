# R4 execution reliability contract

Input: latest full R3 source supplied in this chat and the actual failure screenshot.
Authorized: automatic text-provider failover for project tasks, shared task context, bounded retries, correct provider attribution, real intake dispatch, news input validation, resumable media stages, UI/HTTP/regression validation and a full source ZIP.
Protected: ALL public/space-studio geometry, lighting, materials, cameras, assets, original 3D approved layout; existing credentials, user data, approvals, sandbox and publishing safeguards. Do not auto-deploy or publish. No paid external test calls.
Acceptance: A fails -> B receives the identical request and tool-result context; no replayed file write or publish; bad output handled; all candidates blocked is explicit, bounded and recoverable; reviewer cannot secretly reuse the worker identity; confirmed-spec gate remains; protected assets hash-identical.
Testing: isolated local HTTP provider fixtures + actual app/browser; tests are not real vendor inference or Windows certification. Preserve and report that boundary.
