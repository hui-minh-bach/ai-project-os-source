# R8 acceptance and exact scope

Baseline is delivered R7, not recovered unpublished code. Requirement source is the user's Commercial Check conversation: restore idea-source entry, multiple AI per role, illustrated narrated video, reception/progress versus final outputs.

## Executed gates
- Delegated Project Map controls under unchanged CSP; text input and existing GitHub panel route.
- Ordered multi-member groups with revision checking and legacy primary compatibility. Two real task worktrees run on two synthetic AI endpoints, a third reviews; real file writes, child tests and Git merges.
- Prompt/path contract to image provider corrected. No silent procedural fallback; explicit uploaded/AI/procedural choices. Upload signatures, bounds and path fences.
- Selected speech provider and voice preserved across scenes; voice preview and per-user setup. Images and cost consent isolated by project. Visual crossfades do not overlap spoken phrases.
- Reception owns assignment/progress; final panel contains artifacts. Production screenshots are in evidence/recovery-r8/browser.
- Full regression/syntax, protected assets and ZIP checks recorded in verification.json and SOURCE_SHA256.json.

## Not certified
Windows 10/11 runtime, GPU/3D FPS, real account quotas/failover, live paid image/voice calls, GitHub import with a real account, Piper public download/Windows neural speech, Vercel/Supabase real provisioning and RLS. Broader arbitrary A-Z products, signing and pilot duration remain open. No external billable resources created.

## Reproduce
npm run check
npm test
npm run test:recovery
npm run verify:recovery-ui

Browser test dependencies (QA only): Python requests, Playwright, Chromium, eSpeak, FFmpeg/FFprobe; no external AI key required. Direct localhost browser navigation is blocked in the authoring environment. The harness loads shipped HTML/CSS/classic JS in memory and bridges authenticated HTTP to the real isolated app. It applies the production CSP after loading code and checks a blocked inline-event positive control. It does not test network script loading, WebGL, real Windows or browser streaming audio playback. Artifact HTTP/Range/codec checks are separate. The diagnostic MP4 is not a real-news deliverable or a quality sample for Piper.

## Follow-up defects found and closed while executing QA
- The global upload extension list had not included PNG/JPEG/WebP; fixed, bounded to 20 MB and verified file signatures rather than extensions alone.
- Voice-preview artifacts did not match the shared HTTP streaming shape; fixed metadata/filePath and WAV MIME, with authenticated range handling.
- Safe voice-process environment originally omitted the parent PATH for a partial custom env; now inherits only approved OS keys, never provider secrets.
- Browser runner waits for the exact target project ID, not a condition that could still match the previous project while its async selection loads. This changed test timing, not the consent isolation assertion.
- Every selected Worker now needs an eligible distinct model/account Reviewer before auto-production; configuration with no legal reviewer is rejected early, not halfway through a task.
