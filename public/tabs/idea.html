Kho GitHub — làm việc với repo có sẵn

Đã liên kết GitHub cá nhân (tab Kết nối) thì app lấy được các repo của bạn: nhập một repo thành dự án để đội AI tiếp tục làm ngay trên code có sẵn, lấy issue làm brief giao việc, và khi xong đẩy ngược lên GitHub bằng Pull Request. Vercel: repo đã nối Vercel thì PR có bản xem trước tự động; hoặc dùng nút Deploy Vercel ở trên cho workspace này.

Khi nhập repo, app tự đọc hướng dẫn trong repo (README, HUONG-DAN, thư mục docs), tự nhận diện liên kết Vercel trong repo, và lập danh sách việc tiếp tục từ checklist trong hướng dẫn + issue đang mở + ghi chú TODO cho đội AI.
